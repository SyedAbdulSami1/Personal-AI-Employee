# Skill: Skill Creator
## Trigger
Jab koi naya kaam LLM se complete ho

## Steps
1. LLM se jo response aaya usse analyze karo
2. Steps extract karo
3. New SKILL.md file banao .claude/skills/ mein
4. Skill ko register karo server.py mein

## Rules
- Skill naam clear rakho
- Steps simple rakho
- LLM dependency minimize karo
