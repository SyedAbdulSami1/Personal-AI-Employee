# Skill: Hospital CRM Builder
## Trigger
Jab user "hospital CRM" ya "patient management" likhe

## What This Builds
- Patient Registration System
- Appointment Booking
- Doctor Schedule
- Billing & Invoices
- Automated Reminders via WhatsApp

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: FastAPI (Python)
- Database: SQLite (local)
- AI: Groq for smart suggestions

## Steps
1. Database schema banao (patients, doctors, appointments, billing)
2. FastAPI backend banao (CRUD APIs)
3. React frontend banao (dashboard, forms)
4. FTE integration (auto reminders, reports)
5. Demo data add karo

## FTE Actions
- Daily appointment reminders auto-send
- Monthly billing report generate
- Doctor availability check
- Patient history summarize

## Rules
- Demo data realistic rakho
- Pakistani names use karo
- Urdu/English mix UI
